Why it broke & what changed

The app runs on Tailwind CSS v4. The typography plugin was declared the old v3 way (require("@tailwindcss/typography") in tailwind.config.js), which v4 ignores. So every prose class produced zero styling and tables fell back to raw browser defaults.

GFM markdown table → react-markdown + remark-gfm → <table> → prose CSS = empty ❌ → cramped table
GFM markdown table → react-markdown + remark-gfm → <table> → @plugin typography + renderers ✅ → clean table

The fix (2 files)

  1. ai-ui/src/index.css — added @plugin "@tailwindcss/typography"; right after @import "tailwindcss";
  2. ai-ui/src/components/Discussions.jsx — added custom table / thead / th / td / tr renderers to MarkdownView (bordered wrapper, shaded header, padding, zebra rows, horizontal scroll).
